# Reading list

Articles, guides, and design system pages to read later. Search, or filter by system and topic, and group the links by topic to compare how each system handles the same thing.

The links live in `docs/reading-list.json`. After editing it, run `pnpm reading-list` to regenerate `docs/reading-list.md` and the standalone page, `docs/reading-list.html`.
