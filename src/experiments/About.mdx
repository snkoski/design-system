# Experiments

A place to try ideas without touching the real components. Anything here can be playful, rough, or half
finished.

- Experiments live in `src/experiments/`, one folder each, and show up under Experiments in Storybook.
- They aren't exported from the package or included in its CSS, so nothing here reaches a site that uses the
  design system.
- They don't have to follow the design system's rules or patterns: tokens only, tests for everything, and the
  rest are optional here. Two things still hold: an experiment never changes a component or the published
  styles, and the components never import an experiment.
- To graduate, an experiment moves out of this folder and is rebuilt to follow every rule, the same way a new
  component is.

Try the effects together in **Together**.
